## 2. Colaboración declarada

| Herramienta | Participación reconocida | Distinción necesaria |
|---|---|---|
| OpenAI Codex | Asistencia en programación, depuración, implementación, pruebas, análisis de código y revisión documental. | Herramienta de asistencia, no persona firmante ni autoridad de aceptación. |
| ChatGPT | Apoyo en planificación, revisión técnica, resolución de problemas y documentación. | Sus propuestas requieren contraste y decisión de la estudiante. |
| Gemini | Servicio de IA integrado funcionalmente en PluriOne para generar contenido de campañas. | Es parte del producto; no confirma envíos ni reemplaza la revisión humana. |

No se declaran coautores humanos adicionales, firmas, aprobaciones ni cuentas de GitHub pertenecientes a estas herramientas. El historial de Git registra operaciones de desarrollo; no se utiliza para inventar autoría o personalidad jurídica de una herramienta.

## 3. Uso responsable y límites

Las propuestas de código y texto se contrastan con implementación y pruebas. No deben enviarse a herramientas externas contraseñas, tokens, credenciales, listados de contactos o evidencia privada sin base y autorización. Las campañas generadas se revisan antes de guardarse y enviarse. Las respuestas de IA pueden contener errores y no constituyen prueba de resultados ni aceptación formal.

Las capturas del expediente proceden de ejecuciones auténticas de la aplicación con datos sintéticos cuando así se indica. No se generaron imágenes de resultados con IA. Los resultados reales confirmados por la responsable se distinguen de las comprobaciones reproducibles disponibles en el repositorio.
